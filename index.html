home-assistant

A personal, single-user application operated by an individual developer.

This application connects the developer's own Google Calendar to the developer's own Home Assistant instance running at home, so that the morning schedule can be announced on a smart speaker in the home.

The application is used only by the developer himself. It is not distributed, it is not offered to the public, and there is no sign-up.

これは開発者個人が利用するアプリです。開発者自身の Google カレンダーと、自宅で運用する Home Assistant を連携させ、朝の予定を自宅のスマートスピーカーで読み上げるために使います。 一般公開や利用者募集は行っていません。
